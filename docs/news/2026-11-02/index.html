政策・規制

AI学習に使ってよいかをrobots.txtで一括指定へ　Googleは2027年に対応、Microsoftは2027年2月から適用、Anthropicも実装を開始

サイトの内容をAIの学習に使ってよいかを、AI企業ごとではなく1つの書き方でまとめて伝える仕組みに、Google、Microsoft、Anthropicが10月30日に対応を表明した。robots.txtに共通の名前「__usage_ai-training」を書き、拒否や許可を示す。前号で伝えたOpenAIに続き、主要各社の時期と条件が出そろい始めた。

業界動向

Apple、中国でApple Intelligenceを提供へ　AlibabaのQwenをSiriや作文ツールで利用、12月のiOS 27.3で一般提供

Appleは10月31日、中国のiPhone利用者向けにApple Intelligenceを提供すると発表した。11月4日から開発者向けベータで試験を始め、12月のiOS 27.3で一般提供する。Siri、作文ツール、ビジュアルインテリジェンスの一部では、Alibabaの大規模言語モデル「通義千問（Qwen）」を使えるようにする。

Apple Newsroom（中国）
政策・規制

IPA、2027年度に始める新試験「データ・AI」領域のサンプル問題を公開　プロフェッショナルデジタルスキル試験（仮称）の科目B

情報処理推進機構（IPA）は10月30日、2027年度から始める予定の新しい試験制度について、「プロフェッショナルデジタルスキル（データ・AI）試験（仮称）」の科目Bのサンプル問題を公開した。データやAIを業務で扱う人材を測る新しい区分で、出題の形を前もって確かめられる。

IPA（情報処理推進機構）
研究

Microsoft Research、Copilotの評価用に「架空の会社」のデータを自動で作る仕組みを公開　評価データづくりを数日から自動処理に

Microsoft Researchは10月30日、Microsoft Copilotの品質を測るために、実在の会社に似せた架空の会社のデータと質問を自動で作る仕組みを紹介した。顧客のデータを使わずに、会議の要約などの評価を業界ごとに行える。社内のチームが評価や回帰テストに使っている。

Microsoft Research Blog
