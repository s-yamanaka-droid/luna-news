政策・規制

政府、「AI・デジタル改革推進会議」を初開催　年内に中間整理、中小企業のAI導入支援は3年で40万社目標

政府は10月22日、デジタル行財政改革会議を衣替えした「AI・デジタル改革推進会議」の初会合を首相官邸で開き、デジタル庁が議事次第と資料を公開した。AIを前提に規制や制度を見直す「AI・デジタル改革原則」やアクションプランなどを年内に中間整理する方針を示し、人手不足業種や中小企業のAI活用を短期で加速するプランも年内をめどに作るとした。

デジタル庁
ツール更新

LINEヤフー、飲食店の電話予約をAIが受ける「LINE AI予約」　月1万円から、トレタ予約台帳と連携

LINEヤフーは10月22日、飲食店にかかってくる電話にAIが24時間365日応対する「LINE AI予約」の正式提供を始めた。トレタの「トレタ予約台帳」と連携して空席を確かめ、予約をその場で確定する。料金は初期費用0円、初月無料で、月契約は月額1万円（税別）からだ。

LINEヤフー
業界動向

AnthropicとOpenAI、AIの共通規格を財団に寄贈　「Agent Skills」と「Open Responses」

Linux Foundation傘下のAgentic AI Foundation（AAIF）は10月22日、AnthropicのAIエージェント向け手順の標準「Agent Skills」と、OpenAIのLLM API共通仕様「Open Responses」など4つを新たに受け入れると発表した。特定の企業に縛られない共通の規格として、財団のもとで開発を続ける。

Agentic AI Foundation（Linux Foundation）
セキュリティ

1Password、AIエージェントにパスワードを見せず代理ログイン　個人・ファミリー版は追加料金なし

1Passwordは10月22日、個人向けAIエージェントが利用者の代わりにWebサイトへログインする際、パスワードをエージェントに渡さずに済む「1Password for Agents」を発表した。利用者が自分の端末で承認すると、1Passwordがログイン画面に直接入力し、エージェントは認証情報を受け取らないまま作業を続ける。

1Password
セキュリティ

AWS、AIでコードの脆弱性を検証・修正する「Continuum」を一般提供　米国2リージョン、100万行200ドルから

AWSは10月22日、コードの脆弱性を見つけ、実際に悪用できるかを隔離環境で確かめたうえで修正案まで出すサービス「AWS Continuum for code vulnerabilities」の一般提供を始めた。複数の最先端AIモデルを使い分ける仕組みで、提供地域は米国東部（バージニア北部）と米国西部（オレゴン）の2つだ。

AWS
業界動向

Google、AIエージェントごとに隔離した小型VMを用意する「Agent Compute Engine」　数カ月内にプレビュー

Google Cloudは10月22日、AIエージェント1つずつにハードウェアで隔離した小型の仮想マシン（マイクロVM）を割り当てる計算サービス「Agent Compute Engine」を発表した。すでにGeminiのエージェントを支えており、Google Cloudの利用者向けには今後数カ月でプレビュー提供する。

Google Cloud
ツール更新

OpenAI、選択肢から素早く判定する「Decisions API」を一般提供　入力100万トークン0.10ドル

OpenAIは10月22日、文章や画像を読んで「はい／いいえ」の確率や選択肢、点数といった決まった形の答えを返す「Decisions API」を一般提供にした。10月6日にベータで公開しており、1回で扱える質問を200から400に増やした。

OpenAI
新モデル発表

Canva、初の自社画像生成AI「Craft」　構成を計画してから描く、全ユーザーに提供

Canvaは10月22日、自社の研究部門が一から開発した初の画像生成モデル「Canva Craft」を公開した。まず画面の構成を計画し、その計画をもとに画像を描く2段階の仕組みで、世界のすべてのCanva利用者が「Dream Lab」から使える。

Canva
業界動向

Uber、全社員3万人超にAIエージェント「ChatGPT Work」　1,000人の試験導入から拡大

OpenAIは10月22日、Uberが業務用AIエージェント「ChatGPT Work」を全社に導入すると発表した。1,000人の試験導入から広げ、世界の3万人超の社員が使えるようにする。

OpenAI
ツール更新

Replit、障害を調べて直す「Monitoring Agent」　修正の自動公開も選べる

Replitは10月22日、公開中のアプリで起きた障害を調べ、修正を確かめて本番に反映できる「Monitoring Agent」を発表した。自動で公開するかどうかは利用者が選ぶ。
