Anthropicは11月5日、銀行やカードの口座をつなぎ、支出や請求をClaudeに聞ける「Personal Finance」をベータで公開した。接続にはPlaidを使い、Claudeは残高や取引を読むだけで、お金を動かすことはできない。対象は米国のPro・Max・Ultraプランだ。

Google、動画生成の「Gemini Omni 1.2 Flash」を一般提供　15秒まで生成・編集でき、料金は前版から30%値下げ

Googleは11月5日、動画生成モデル「Gemini Omni 1.2 Flash」を発表した。1本で生成・編集できる長さを10秒から15秒に延ばし、料金を前版のGemini Omni 1.1から30%下げた。Gemini APIや企業向けのGoogle Cloudで一般提供し、Google Vidsなどにも広げる。

OpenAIは11月4日、画像生成の新版「Images 2.6」を公開した。従来より50%速く生成し、キャラクターや商品を動かすGIFも作れる。ChatGPTとCodexのすべてのサブスクリプションプランで世界同時に使え、APIでは速さ重視の「Flare」と精度重視の「Sunburst」の2種類を出す。

PFN、翻訳特化の「PLaMo 3 Translate」の重みを公開　53言語に対応、0.8Bから31Bまで4サイズ　社外にデータを出さず翻訳

Preferred Networks（PFN）は11月5日、翻訳に特化した大規模言語モデル「PLaMo 3 Translate」の重みを公開した。日本語と英語を含む53言語に対応し、スマートフォンやノートPC、社内サーバーで動かせる。原文や訳文を外部のサーバーに送らずに翻訳できる。

Preferred Networks

Stripe、AIエージェントから決済データを分析できる仕組みを全ユーザーに提供　MCPとQueries API、300超のテーブルを使うReports API

Stripeは11月5日、ClaudeやCursorなどのAIエージェントから、自社の決済データを言葉で分析できるようにしたと発表した。Stripe MCP、Queries API、Reports APIの3つの経路を、すべてのStripeユーザーが使える。結果の裏にあるSQLを確かめ、直すこともできる。

医学書院、NTT、NTTドコモビジネスは11月5日、Ubieと組み、医療従事者の質問に根拠と出典を示して答える生成AIの共同実証を11月から始めると発表した。3社が開発する「医療AI情報プラットフォーム」とUbieの「ユビー生成AI」をつなぎ、NTT東日本関東病院で使う。

旭化成、AIと自動化で材料開発を自律的に回す「スマートラボラトリー」を開設へ　半導体向け材料の開発実験数を約4倍に

旭化成は11月5日、材料の設計から実験、顧客の製造工程を想定した評価までをAIと自動化で繰り返す「スマートラボラトリー」を静岡県富士市に開設すると発表した。2027年1月に稼働する予定で、半導体向けの感光性絶縁材料「パイメル」の開発実験数を従来の約4倍に増やす。

GitHub NextとMicrosoft Research、AIが書いたコードを数学的に証明する「PDD Kit」を公開　Rustが対象の研究試作

GitHub NextとMicrosoft Researchは、AIが書いたコードが仕様どおりに動くことを数学的な証明で確かめる研究試作「PDD Kit（Proof-Driven Development）」を公開した。対話で要求を検証できる仕様にまとめ、コーディングエージェントが実装と証明を書き、検証ツールVerusが確かめる。現在はRustが対象だ。

Baiduは11月5日、事前学習を終えた段階の基盤モデル「ERNIE 5.5 Flash Base」の重みをHugging Faceで公開した。総パラメータは280Bで、1トークンごとに動くのは14B。学習時の文脈長は12.8万トークンで、追加学習と推論では100万トークンまで扱える。
