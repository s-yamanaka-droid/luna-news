ツール更新

AWS、AIの仕事場「AWS Quick」を更新　会話で業務フローを作成、複数エージェントの同時作業や日本語対応も

AWSは11月20日（米国時間）、業務向けAIワークスペース「AWS Quick」の更新を発表した。チャットで説明するだけで業務フローを組み立てられるようにし、複数のエージェントが1つの依頼を同時に分担する機能や、日本語を含む言語対応を加えた。

AWS
ツール更新

AWS、書類から欲しい項目を言葉で指定して抜き出す「Amazon Textract Insights」を正式提供　値ごとに確信度と根拠ページ

AWSは11月20日（米国時間）、書類から取り出したい項目を自然な言葉で指定すると、構造化したデータで返す生成AI機能「Amazon Textract Insights」の一般提供を始めた。値ごとに確信度と、どのページから取ったかの根拠が付く。

AWS
研究

慶應大・東海大・NECなど、1回の採血でがんを早期に見つけるAI検査法を開発　卵巣がんで特異度99.5%・感度65%、6種類のがんで臨床試験

慶應義塾大学医学部、東海大学、湘南医療大学、NECの共同研究チームは11月20日、血液中の「糖ペプチド」と腫瘍マーカーをAIで解析してがんを早期に見つける検査技術「CSGSA法」を開発したと発表した。卵巣がんでは、内部検証で従来の単一マーカーを上回る結果を示した。

NEC（慶應義塾大学・東海大学・湘南医療大学と共同発表）
ツール更新

Amazon Polly、数分の録音から本人の声を再現する「音声クローン」を提供開始　7言語対応、作成のたびに本人同意を確認

AWSは11月19日（米国時間）、音声合成サービス「Amazon Polly」で、話者の数分の録音からその人の声で読み上げる音声を作る「音声クローン」の一般提供を始めた。利用は申請制で、声を作るたびに話者の同意を得ていることの確認を求める。

AWS
セキュリティ

Sakana AI、サイバー防御とAIの安全性を研究する「Security Research Group」を設立　事業から切り離し、成果やベンチマークを公開へ

Sakana AIは11月20日、AIを使った集合的なサイバー防御と、AIシステム自体の安全性を研究する独立チーム「Security Research Group」の設立を発表した。事業とは切り離した組織として、研究成果や再現できるベンチマーク、実践的な指針を公開するとしている。

Sakana AI
業界動向

GitLab、AIエージェント基盤「Duo Agent Platform」のクレジット効率を最大2倍に　モデルへの要求回数を減らし、節約分を利用者へ

GitLabは11月19日、AIエージェント基盤「GitLab Duo Agent Platform」で、1つの作業に必要なAIモデルへの要求回数を減らしたと発表した。多くの顧客で、同じクレジット（GitLab Credits）で最大2倍の作業ができるようになるとしている。

GitLab
業界動向

AMDとUnsloth、PC上でAIを動かす「Unsloth Desktop」がRyzen AIのNPUに対応　100超のエージェント系アプリから省電力で利用

AMDは11月19日（米国時間）、AIモデルを手元のPCで動かすアプリ「Unsloth Desktop」が、同社のXDNA 2アーキテクチャのNPU（AI専用の処理装置）に対応したと発表した。Unsloth Desktopが対応する初めてのNPUだとしている。

AMD
研究

Apple、普通のカメラ映像から距離をメートル単位で推定する「Depth Pro 2」を公開　写真も動画も1つのモデルで、コードと重みも

Appleの機械学習研究チームは11月、普通のカメラで撮った写真や動画から、画素ごとの距離をメートル単位で推定する研究「Depth Pro 2」を公開した。物の輪郭のくっきりさと、動画でのちらつきのなさを両立したとしており、コードとモデルの重みも公開した。

Apple Machine Learning Research
