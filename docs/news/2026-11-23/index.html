数学者アルペゲ氏、Claudeと共同で「リーマン予想」を証明したと発表　Leanコミュニティが形式証明の正しさを認める共同声明

数学者のレヴェント・アルペゲ（Levent Alpöge）氏が、AI「Claude」と共同で数学の最難問の一つ「リーマン予想」を証明したとする4ページのノートと、定理証明支援系Leanによる形式証明を公開した。Lean/Mathlibコミュニティは11月21日、証明が正しいと確信しているとの共同声明を出した。

OpenAIのチーフサイエンティスト、開発各社に「越えない上限」の共通化を提案　予測の正確さを示す指標を物差しに、自社の測定値も公開

OpenAIのチーフサイエンティスト、ヤクブ・パホツキ（Jakub Pachocki）氏は11月22日、公式サイトで、AIモデルの賢さを測る共通の物差しとして「パープレキシティ」を使い、開発各社が越えないと約束する上限を決めることを提案した。自社モデルの内部測定値もあわせて公開した。

AIの能力評価を行う米非営利団体METRは11月20日、AI研究開発に関わるモデルの能力が急速に伸び、測定が難しくなっているとする2026年第4四半期の報告を公開した。これまで危険度の上限を見積もるのに使ってきた評価の一部が、役に立たなくなりつつあるとしている。

研究

Hugging Face、AIエージェントの「作業環境」ごとにモデルを合わせる「ハーネスアダプター」を公開　少ないトークンで正答率を改善

Hugging Faceは11月20日、AIエージェントを動かす作業環境（ハーネス）ごとに、オープンモデルを小さな追加学習で合わせる「ハーネスアダプター」を公開した。Qwen3.8-27Bに対し、3種類のハーネス向けにそれぞれLoRAを学習させ、正答率と使うトークン量の両方が改善したと報告している。

AIの推論基盤を提供する米Basetenは11月20日、判断や予測の課題向けに調整したオープンモデル「bison-1」と「groundhog-1」を公開した。bison-1は、Artificial Analysisの「Decision Index v2.1」で19モデル中1位になったとしている。

AWS、複数リージョンのAI推論を1つの窓口にまとめる「SageMaker HyperPod Global Inference Gateway」を発表　障害時は自動で切り替え、東京を含む13リージョン

AWSは11月20日（米国時間）、Amazon SageMaker HyperPodで動かすAIモデルの推論を、複数のリージョンやクラスターにまたがって1つのエンドポイントで受け付ける「Global Inference Gateway」を発表した。混み具合や距離をもとに振り分け先を選び、障害時は別のクラスターに自動で切り替える。
