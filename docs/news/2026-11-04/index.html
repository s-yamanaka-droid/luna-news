ツール更新

Apple、Siri AIを全開発者に開放　App Intentsで他社アプリの操作に対応、iOS 27.3ベータで開発者向けプレビュー

Appleは11月3日、iOS 27.3などのベータ版で、どの開発者でも自分のアプリをSiri AIにつなげられる開発者向けプレビューを始めた。App Intentsを使えば、配達状況の確認や予約、注文といったアプリ独自の操作をSiri AIが代わりに実行できる。App Storeへの提出受付は春から始まる。

Apple
業界動向

Anthropic、IPO申請書の修正版で7〜9月期を開示　売上高は169億ドルで前年同期の約12倍、営業損益は5.67億ドルの赤字

Anthropicは11月2日、新規株式公開（IPO）に向けて米証券取引委員会（SEC）に出した登録届出書の修正版（S-1/A）で、2026年7〜9月期の業績を開示した。売上高は169億5600万ドルと前年同期の約12倍に増えたが、短期契約で調達した計算資源の費用がかさみ、営業損益は5億6700万ドルの赤字だった。

Anthropic（米SEC提出書類）
業界動向

Salesforce、顧客対応AIのCrestaを買収へ　音声エージェントと会話分析をService Cloudに統合

Salesforceは11月2日、顧客対応向けAIを手がけるCrestaを買収することで最終合意したと発表した。Crestaの音声エージェントと会話分析をService Cloudと組み合わせ、一つひとつの会話を顧客の履歴や対応の結果と結びつける。買収額は公表していない。

Salesforce
新モデル発表

AWS、Amazon BedrockでOpenAIの「GPT-6.1 Terra」を一般提供　Step Functionsの業務フローをAIエージェントの道具として呼び出せるように

AWSは11月2日の週次まとめで、OpenAIの「GPT-6.1 Terra」をAmazon Bedrockで一般提供したと紹介した。あわせて、AWS Step Functionsで組んだ業務フローを、AIエージェントがMCP経由で道具として呼び出せるようにした。

AWS
ツール更新

Snowflake、AIエージェントに社内の用語の定義を渡す「Business Ontology」を発表　利用と費用をまとめて管理する「Cortex AI Gateway」は一般提供

Snowflakeは11月3日、オンラインイベント「Expedition 2026」で、社内で承認した業務用語の定義をAIエージェントに渡す「Business Ontology」や、エージェントの接続・ツール呼び出し・モデル利用・費用を1つの方針で管理する「Cortex AI Gateway」の拡張を発表した。

Snowflake
ツール更新

GitHub Copilot、JetBrainsのエージェント作業環境「Air」で利用可能に　クラウドの作業は隔離されたコンテナで実行

GitHubは11月3日、JetBrainsの「Air」でGitHub Copilotを使えるようにしたと発表した。Airはコーディング作業をAIに任せ、進め方を指示し、結果を確かめる場で、IDEの中でもクラウドでも作業を動かせる。いま契約しているCopilotのプランをそのまま使える。

GitHub
セキュリティ

AIエージェントが実在のOSSの弱点を直せるかを測る「CWE-bench v2」公開　100課題・91種類、首位の正答率は67.8%

Hugging FaceとCollinear AIの研究者は11月3日、AIエージェントが実在するオープンソースのリポジトリでセキュリティ上の弱点を見つけ、既存の機能を壊さずに直せるかを測る評価「CWE-bench v2」を公開した。誰でも動かせる100課題の公開セットを用意した。

Hugging Face / Collinear AI
研究

Ai2、長い文書で「値の変化」を追えるかを測る評価「StateBench」を公開　最難関の長い問題では最新モデルも正答率13%以下

米非営利研究機関のAi2は11月3日、言語モデルが長い文書の中で、変数の値がどう変わったかを正しく追えるかを測る評価「StateBench」を公開した。4段階の難しさがあり、最も難しい段階の長い問題では、試した最新モデルの正答率が13%以下に下がった。
