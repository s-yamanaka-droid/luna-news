OpenAI、Pierreを買収へ　CodexのファイルやDiff表示を支える開発ツール企業、Code StorageもCodexに統合

OpenAI、バグ報奨金を引き上げ　中・高・重大の報奨金を平均4倍超に、ボーナス込みで最大約17万ドル

OpenAIは11月2日、外部の研究者が脆弱性を報告した際に支払うバグ報奨金を引き上げると発表した。深刻度が中・高・重大の報奨金の中央値を平均で従来の4倍超にし、品質やロイヤルティに応じたボーナスも新設した。未払いの報告や直近30日の支払いにもさかのぼって適用する。

NVIDIA、CUDA 13.5でVera Rubinへの対応を正式版に　Windows on ArmをDGX Stationに拡大、行列計算の高速化も

東北大とアイシン、STT-MRAMを載せた16nmのAIチップを開発　電源投入からOS起動まで65.7ミリ秒、物体検出の電力は約50分の1

東北大学とアイシンは11月2日、32MBのSTT-MRAMを組み込んだ16nm FinFETのAIチップを開発したと発表した。電源投入からOS起動までを65.7ミリ秒にし、従来の約39倍に速めた。物体検出1フレームのエネルギーは従来の約50分の1としている。
