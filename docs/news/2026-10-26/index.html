創薬AIのPathos、2億3,700万ドルを調達　評価額約30億ドル、BMSが主導

米Pathos AIは10月23日、シリーズEで2億3,700万ドルを調達したと発表した。調達後の企業価値は約30億ドルで、米製薬大手Bristol Myers Squibb（BMS）が主導した。多数のAIエージェントで医薬品開発のデータを集約する自社基盤「Foundry」の拡大と、がん領域の臨床開発に充てる。

GitHub、Teamsの通知からCopilotに修正を頼めるように　旧アプリは11月16日に終了

GitHubは10月23日、Microsoft Teams向けアプリにCopilotを統合したと発表した。Teamsに届いた通知に対して「@GitHub」と呼びかけると、Copilotが調査や修正を行い、プルリクエストまで作る。従来の「GitHub notifications」アプリを1つにまとめ、旧アプリは11月16日に終了する。

Amazon Bedrockのウェブ検索、参照先を最大100ドメインまで指定・除外　利用者の地域も指定可能に

AWSは10月23日、Amazon Bedrockの「Web Search」に、検索先ドメインの指定・除外と、利用者の地域を指定する機能を追加した。AIの回答の根拠になる検索結果を、信頼できるサイトや地域に合わせて絞り込める。

GitHub Copilotの利用状況API、ツール別の集計に対応　Claude Code・Codex・OpenCodeなどからの利用も

GitHubは10月23日、Copilotの利用状況を取得するAPIに、どのツールから使われたかを集計する項目を追加した。これまで拾えなかったOpenCodeなどエディタ外のツールからの利用も、リクエスト数やトークン数として見られる。
