Baidu、280Bパラメータの基盤モデル「ERNIE 5.5 Flash Base」の重みを公開　動くのは14B、推論で100万トークンに対応

Baiduは11月5日、事前学習を終えた段階の基盤モデル「ERNIE 5.5 Flash Base」の重みをHugging Faceで公開した。総パラメータは280Bで、1トークンごとに動くのは14B。学習時の文脈長は12.8万トークンで、追加学習と推論では100万トークンまで扱える。

GitHub NextとMicrosoft Research、AIが書いたコードを数学的に証明する「PDD Kit」を公開　Rustが対象の研究試作

GitHub NextとMicrosoft Researchは、AIが書いたコードが仕様どおりに動くことを数学的な証明で確かめる研究試作「PDD Kit（Proof-Driven Development）」を公開した。対話で要求を検証できる仕様にまとめ、コーディングエージェントが実装と証明を書き、検証ツールVerusが確かめる。現在はRustが対象だ。

旭化成は11月5日、材料の設計から実験、顧客の製造工程を想定した評価までをAIと自動化で繰り返す「スマートラボラトリー」を静岡県富士市に開設すると発表した。2027年1月に稼働する予定で、半導体向けの感光性絶縁材料「パイメル」の開発実験数を従来の約4倍に増やす。
