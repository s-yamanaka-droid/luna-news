ツール更新

Google、AIが画面を組み立てる共通仕様「A2UI」の安定版1.0を公開　React・Flutter・SwiftUIなどで描画、AtlassianやBloombergが採用

Googleは11月11日、AIエージェントが文章の代わりに入力フォームやグラフなどの画面を返すための公開仕様「A2UI」の、初の安定版となる1.0を公開した。エージェントは画面の構成だけを伝え、アプリ側が自分の部品で描画する。Web、Android、iOS向けの描画用SDKと、Python・TypeScript・Dart向けのエージェント用SDKを公開した。早期の採用企業としてAtlassian、Alation、Bloomberg、ByteDanceを挙げている。

ツール更新

AWS、手元のPCでAWSを再現する「AWS Emulator」を公開　追加料金なし、開発と保守はAIエージェントが担当

AWSは11月11日、自分のPCの上でAWSのAPIを再現する「AWS Emulator」を公開した。AWS CLIやSDK、コーディングエージェントが手元の接続先につなぎ、クラウドに出さずにアプリを試せる。追加のサービス料金はかからない。AWSによると、このソフトはAIエージェントが開発と保守を担っており、本物のAWSと同じ結果を返すかを確かめるテストの成績をサービスごとに公開する。

新モデル発表

ElevenLabs、音声認識「Scribe v3」と「Scribe v3 Live」を公開　102言語で単語の誤りを前版より27%減らし、リアルタイムの話者分けに初対応

ElevenLabsは11月10日、音声を文字にするモデルの新版「Scribe v3」と、リアルタイム向けの「Scribe v3 Live」を公開した。録音向けのScribe v3は、102言語で単語の誤りを前版のScribe v2より27%減らしたとしている。Scribe v3 Liveは、誰が話したかを分ける話者分けにリアルタイムで初めて対応し、会話の流れから「話し終わり」を判断する。数値はいずれも同社の公表値。

Google、Geminiを使えるメガネを12月10日に発売　Gentle Monsterは449ドルから、Warby Parkerは395ドルから、まず米国と韓国

業界動向

アルティウスリンク、電話応対AIの導入から育成・運用までを担う「AI Voice サービス」を開始　一次受付で終わらせず、用件の完結を目指す

コンタクトセンター大手のアルティウスリンクは11月11日、電話で人と自然に会話して用件を完結させるAIオペレーターを、導入から育成、運用、品質改善まで一体で提供する「AI Voice サービス」を始めた。AIオペレーターを人と同じように育成・評価・改善し、任せる業務を広げていく。料金や具体的な数値目標、使っている技術は発表に記載がない。

政策・規制

豪政府、最先端AIの開発企業に安全対策を義務づけへ　第三者による評価の受け入れと事故の報告を求め、罰則を執行する規制機関の新設も提案

オーストラリア政府は11月10日、最先端のAIモデルを開発する企業に、安全とセキュリティの対策を法律で義務づけると発表した。オーストラリアで事業をしようとするすべての最先端AI企業が対象で、第三者による評価の受け入れ、事故の速やかな報告、安全の枠組みの公表などを求める。AIの安全を担当する規制機関の新設を提案し、従わない企業には「重大な罰則」を科せるようにする方針だ。
