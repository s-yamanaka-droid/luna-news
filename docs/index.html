Replit、AIエージェントが事業の備品を買い、Google広告を出せるように　購入は合計額を確認して承認、StripeのLinkとVisaを利用

Replitは11月12日、開発AI「Replit Agent」に2つの機能を加えたと発表した。1つは事業に必要な品物をAIが探して購入の手前まで進める機能で、事業主が合計額を承認するまで請求は起きない。Stripeの「Link」とVisaの仕組みを使う。もう1つはGoogle広告の作成と運用の支援で、AIが広告文や画像、1日の予算案を用意し、事業主が確認して出稿する。

Ai2、AIが「質問の前提の間違い」に気づけるかを測る8,115問の「XYBench」を公開　主要モデルは本当の目的より聞かれたことに答えがち

米国のアレン人工知能研究所（Ai2）は11月13日、AIアシスタントが利用者の思い違いに気づき、本当の目的に向けて答えられるかを測るベンチマーク「XYBench」を紹介した。8,115問からなり、プログラミングと、料理や家の修理などの日常の作業を扱う。試した主要モデルはいずれも、質問の裏にある目的より、聞かれたことそのものに答える傾向があった。

Ai2（アレン人工知能研究所）

IBM、AIへの入力で「指示」と「データ」を専用の記号で分ける記法「LLMON」を公開　Granite 4.1の試作モデルで、紛れ込んだ命令に従いにくく

IBMは11月12日、AIモデルに渡す文章の中で、従うべき指示と、読むだけのデータを専用の記号で区切る記法「LLMON」（レモン）を公開した。対応する試作モデルとして、Granite 4.1の3Bと8Bの2つをHugging Faceで公開している。文書やツールの結果に紛れ込ませた命令にAIが従ってしまう「プロンプトインジェクション」に強くなるとしているが、実験的な試作で、本番での利用はまだ勧めていない。

llama.cppとggmlがバージョン1.0.0に　手元のPCでAIを動かす定番ソフト、互換性が崩れる変更はメジャー番号で示す方針

AIモデルを手元のパソコンやサーバーで動かすためのオープンソースソフト「llama.cpp」と、その土台のライブラリ「ggml」が11月13日、そろってバージョン1.0.0になった。今後は番号の付け方を決まりに沿わせ、これらを組み込んだソフトが動かなくなるような変更は、いちばん左の番号（メジャー）を上げて知らせる。開発チームがHugging Faceのブログで発表した。

ggml-org / Hugging Face

那須ハイランドパーク、園内カメラが来園者を自動で撮りAIが動画にする「プレスマ」を正式導入　顔を登録していない人は自動でぼかす

吉積ホールディングスは、AIによる自動撮影サービス「プレスマ」の正式な提供を、栃木県の遊園地「那須ハイランドパーク」で始めたと発表した。園内の約50台のカメラが来園者を自動で撮り、AIがその日のハイライト動画を作る。顔を登録した本人だけを見分け、登録していない人の顔は自動でぼかす。2025年11月からの試験提供で、登録者は累計約1万人になった。AI Watchは11月12日の発表と伝えている。

吉積ホールディングス

Cloudflare、AIで侵入を試みるツールの通信が10月から約30倍に増えたと報告　3日間で50系統超を観測、「ARTEX」とその派生が6割超

Cloudflareは11月13日、AIエージェントが侵入テストや攻撃の手順を自動で進めるツールの広がりについて報告した。3日間で50を超える系統のツールが世界中の顧客を走査しているのを観測し、こうしたツールからの1日あたりの通信は10月1日から約30倍に増えた。11月12日時点で「ARTEX」とその派生が6割超を占める。侵入の原因としては、期限のない認証トークンの管理不備を挙げた。

Cloudflare
