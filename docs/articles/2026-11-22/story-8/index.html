Apple、普通のカメラ映像から距離をメートル単位で推定する「Depth Pro 2」を公開　写真も動画も1つのモデルで、コードと重みも

Appleの機械学習研究チームは11月、普通のカメラで撮った写真や動画から、画素ごとの距離をメートル単位で推定する研究「Depth Pro 2」を公開した。物の輪郭のくっきりさと、動画でのちらつきのなさを両立したとしており、コードとモデルの重みも公開した。

ニュースの要点

  • 1枚の写真、動画、ライブのカメラ映像を、1つのネットワークで入力の解像度のまま処理する
  • 従来法は、複数フレームを使う方式は安定性、1枚ずつの方式は輪郭のくっきりさを優先する傾向があったと分析
  • 距離の正確さ・輪郭のくっきりさ・時間的な安定性・処理速度のすべてで従来研究を上回ったとしている
  • 大きさの異なる複数のモデルを、コードと重みとあわせて公開

スマホのカメラが、メジャーになる。

何を発表したか

Apple Machine Learning Researchのページによると、Depth Pro 2は1台の普通のカメラの映像から、全画素の距離をメートル単位で推定する手法である。研究チームは従来の手法を分析し、複数フレームを使う方式は時間的な安定性を、1枚ずつ処理する方式は境界のくっきりさを優先するという、どちらかを取る関係があったと指摘した。

Depth Pro 2は、画像と動画の両方を扱う1つの大規模なネットワークを学習させ、入力の解像度のまま深度を出すことで、この関係を乗り越えたとしている。距離の正確さ、くっきりさ、時間的な安定性、処理時間で新たな最良の組み合わせ（パレート最前線）を示すモデル群を公開した。

公開の範囲

論文に加え、GitHubでソースコードとモデルの重みが公開されている。前身の「Depth Pro」は2024年10月に発表され、標準的なGPUで225万画素の深度地図を0.3秒で作れるとしていた。

Depth Pro 2を商用で使えるかどうかの利用許諾の条件や、Apple製品に組み込む予定があるかは発表ページからは確認できず、未確認である。

本誌の考察・実務提案

Lakkanの視点｜スマホのカメラが「メジャー」になる

これは本誌の解釈だが、普通のカメラ映像から実際の距離が安定して取れるようになると、特別な機器を使わずに現場の寸法を測ったり、ロボットや点検の仕組みに奥行きの情報を与えたりしやすくなる。

本誌は、建設・小売・物流などで「写真から大きさや距離を知りたい」業務がある会社は、研究段階の技術として動向を追い、利用条件を確認してから試すことを勧める。これは本誌の提案で、Appleの主張ではない。

現場で試す3つのこと

  1. 写真や動画から寸法・距離を知りたい業務があるか確認する
  2. 試す前に、公開されたコードと重みの利用許諾を確認する
  3. 前身のDepth Proとの違いを社内の技術担当と共有する
