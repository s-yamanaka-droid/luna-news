LINEヤフー、AIエージェント「Agent i」のiOSアプリを提供開始　ウィジェットから音声や画像で話しかけ、登録した情報収集の完了を通知、Android版は順次

LINEヤフーは11月10日、AIエージェント「Agent i」のスマートフォン・タブレット向けiOSアプリを提供開始した。ホーム画面のウィジェットから新規チャットや画像・音声入力を始められ、登録したタスクが終わるとアプリが通知する。Android版は順次提供する予定。

ニュースの要点

  • iOS版のスマートフォン・タブレット向けアプリをApp Storeで提供。Android版は順次提供予定で、時期は示していない
  • ホーム画面からワンタップで起動。ウィジェットから新規チャット、画像入力、音声入力をすぐに始められる
  • タスク機能と通知が連携し、完了をトップ画面で知らせ、未読ならアプリから通知する
  • LINEアカウントかYahoo! JAPAN IDでログイン。Agent iは2026年4月に始まり、領域エージェントはベータ版を含め累計40領域

顧客は、検索せずに通知で知るようになる。

何を発表したか

LINEヤフーは11月10日、AIエージェント「Agent i」のスマートフォン・タブレット向けアプリ（iOS版）の提供を始めた。ホーム画面からワンタップで起動でき、ウィジェットからは新規チャット、画像入力、音声入力をすぐに始められる。Android版は順次提供する予定で、時期は示していない。

アプリはAgent iのタスク機能と通知が連携する。登録したキーワードの最新情報や値下がり、イベント開催などを届けるタスクが終わると、トップ画面で知らせ、未読の場合はアプリから通知する。ログインはLINEアカウントかYahoo! JAPAN IDで、ログインしなくても一部の機能は使える。

Agent iの位置づけ

Agent iは2026年4月に提供が始まったAIエージェントで、分野ごとの「領域エージェント」はベータ版を含めて累計40領域になった。9月24日には、好きなアーティストやキャラクターのイベント、チケット、グッズの情報を整理する「推し活」を加えている。

料金や利用者数は発表文に記載がなく未確認。法人の業務で使うことを想定した機能や管理の仕組みについても、今回の発表では触れていない。

本誌の考察・実務提案

Lakkanの視点｜「待っていれば届く」AIが日常のアプリに

これは本誌の解釈だが、頼んだ調べものの完了を通知で受け取る使い方が、LINEやYahoo! JAPANの利用者に広がると、AIに仕事を「預けて待つ」感覚が一般の人にも当たり前になる。顧客が情報を受け取る経路が、検索からエージェントの通知へ少しずつ移るとみる。

本誌は、新商品や値下げ、イベントの情報を発信している企業に、自社の情報がこうしたエージェントに拾われやすい形で公開されているかを確かめることを勧める。これは本誌の提案で、LINEヤフーの推奨ではない。

現場で試す3つのこと

  1. Agent iに自社の商品名やイベント名でタスクを登録し、どう届くかを試す
  2. 価格や開催日などの情報が、自社サイトで最新の状態になっているか確認する
  3. 社員が業務でAgent iを使う場合のルール（入力してよい情報）を決める
