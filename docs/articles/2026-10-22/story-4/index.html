Walmart、AIエージェントの買い物を受け入れ　MCPで「Agent Gateway」公開

米小売大手のWalmartは10月21日、利用者に代わってAIエージェントが買い物をするための仕組み「Walmart Agent Gateway」と、エージェントごとに購入を管理する「Agent Profiles」、エージェント向けの利用条件を発表した。Agent Gatewayは企業・開発者向けのベータとして始める。

本誌公開 2026-10-22 ｜ 本誌更新 2026-10-22 ｜ 原典の発表・執筆 2026-10-21

発行：Now on AIr 編集部（記事制作にAIを使用）｜編集責任者：山中秀斗

ニュースの要点

  • Agent GatewayはMCP（Model Context Protocol）を使う仕組みで、企業・開発者向けのベータとして開始
  • 発表で名前が出たエージェントはMuse、ChatGPT、Gemini。そのほかも対象とする
  • Agent Profilesは「今後1か月のうちに」開始。購入ごとの承認か、50・100・200ドルなどの上限を選べる
  • エージェントはカード情報を受け取れない。対象地域は発表に明記がなく未確認

お客さんの代わりに、AIが買い物かごを持って来る。

何が発表されたか

Walmartは10月21日、利用者が選んだAIエージェントを通じてWalmartとSam's Clubで買い物ができるようにする取り組みを発表した。発表では、Muse、ChatGPT、Geminiなどのエージェントを例に挙げている。

中心となる「Walmart Agent Gateway」は、MCP（Model Context Protocol）を使ってエージェントが商品を探し、注文できるようにする仕組みだ。同社は、人向けに作られたサイトをエージェントがブラウザで操作する今のやり方は遅く、間違いが起きやすいと説明している。Agent Gatewayは企業と開発者向けのベータとして始める。

購入の管理とエージェントへの決まり

「Agent Profiles」は今後1か月のうちに始める。エージェントごとに専用のプロフィールを作り、その購入を本人の購入と分けて表示する。購入のたびに承認するか、50ドル・100ドル・200ドルといった上限を設けるかを利用者が選び、いつでも変更・削除できる。

エージェント向けの条件も公表した。購入は初期設定で利用者の承認が必要で、上限内でもWalmartが追加の承認を求める場合がある。エージェントは利用者の意図を超えて動いてはならず、カード情報は受け取れず、支払い方法の追加や変更もできない。エージェントの誤りでも通常の返品手続きが使え、条件に違反したエージェントはサイトから締め出す。価格は人が見るものと同じだとしている。

対象地域は発表に明記がなく、本誌では未確認。TechCrunchは、Walmart+の会員でなくても使えると報じた（発表文では未確認）。

本誌の考察・実務提案

Lakkanの視点｜「AIが来店する」前提で売り場を作り直す動き

同じ時期にAmazonがエージェントの購入を締め出したと報じられる中、Walmartは専用の入口と決まりを作って受け入れる側に回った。人が見る画面とは別に、AIが読みやすい入口を用意する発想だ。

日本の中小のネットショップがすぐ同じことをする必要はない。ただ、商品名や在庫、価格、送料が機械にも正しく読める形で整っているかは、検索にもAIにも効く基本だ。まず自社の商品ページを見直しておきたい。これは本誌の提案で、Walmartの推奨ではない。

現場で試す3つのこと

  1. 自社の商品ページで、商品名・在庫・価格・送料が正しく読み取れる形か確認する
  2. AIエージェント経由の注文が来た場合の確認・返品の扱いを想定しておく
  3. MCPなど、AIとサービスをつなぐ仕組みの基本を担当者が把握する
