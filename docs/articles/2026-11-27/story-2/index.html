DeepL、音声翻訳モデル「Aure v2」を発表　翻訳遅延の中央値を半減、日本語など6言語で会議向け製品に自動適用

DeepLは11月26日、東京で開いた初の「Unmute Summit」で、音声翻訳モデル「Aure v2」を発表した。翻訳遅延の中央値を前モデル「Aure」から50％減らし、日本語を含む6言語で同社の音声翻訳製品に自動で適用する。

本誌公開 2026-11-27 ｜ 本誌更新 2026-11-27 ｜ 原典の発表・執筆 2026-11-26

発行：Now on AIr 編集部（記事制作にAIを使用）｜編集責任者：山中秀斗

ニュースの要点

  • 翻訳遅延の中央値が、前モデル「Aure」より50％減
  • 音声から音声へ直接訳すエンドツーエンド型で、強化学習で訓練
  • 対応は英語・ドイツ語・フランス語・スペイン語・日本語・韓国語の6言語。今後追加予定
  • DeepL Voice（オンライン会議・対面会話）とDeepL API for Voiceで、対応言語なら設定なしで有効
  • 社内測定では、英日の誤訳がGoogle Gemini 3.5 Live Translateより32％少ない

訳が出るまでの待ち時間が、半分に。

待ち時間を半分に

DeepLの発表文によると、Aure v2は音声を文字に起こしてから訳すのではなく、音声から音声へ直接翻訳するエンドツーエンド型のモデルで、強化学習で訓練した。翻訳遅延の中央値は、同月前半に発表した前モデル「Aure」と比べて50％短くなった。

対応言語は英語、ドイツ語、フランス語、スペイン語、日本語、韓国語の6つで、今後増やす予定。オンライン会議向けと対面会話向けの「DeepL Voice」、開発者向けの「DeepL API for Voice」で、対応言語では設定なしで自動的に使われる。料金やプランの変更は発表文に記載がない。

比較は自社の測定

品質については、2026年11月の社内調査で、比較した競合6システムよりすべての言語ペアで翻訳品質が高かったとしている。英語と日本語の組み合わせでは、誤訳がGoogle Gemini 3.5 Live Translateより32％少なかった。

測定は10の言語ペアの実際の音声（各1分、人が確認した書き起こし付き）を、各社の公開APIに通して行った。DeepLは、実際の会話では結果が変わる可能性があると注記している。

利用の伸びとして、2026年第3四半期の音声利用時間は前年同期の8倍超、会議での利用は日本で7倍超になったとしている。

本誌の考察・実務提案

Lakkanの視点｜自社の会議音声で確かめる

これは本誌の解釈だが、訳が出るまでの待ち時間が縮むと、通訳を挟んだ会議でも話の流れが途切れにくくなる。海外の取引先との定例など、毎週の会議ほど効果を感じやすい。

一方、品質の数字はDeepL自身の測定だ。社内用語や製品名が多い会議では結果が変わりうるため、実際の会議音声で誤訳の傾向を確かめてから広げたい。

現場で試す3つのこと

  1. 海外との定例会議で、Aure v2が有効になる言語の組み合わせか確認する
  2. 社内用語の多い会議で試し、誤訳の傾向を記録する
  3. 自動で切り替わるため、管理者が利用中の製品と対応言語を把握しておく
