Microsoft Research、Copilotの評価用に「架空の会社」のデータを自動で作る仕組みを公開　評価データづくりを数日から自動処理に

Microsoft Researchは10月30日、Microsoft Copilotの品質を測るために、実在の会社に似せた架空の会社のデータと質問を自動で作る仕組みを紹介した。顧客のデータを使わずに、会議の要約などの評価を業界ごとに行える。社内のチームが評価や回帰テストに使っている。

本誌公開 2026-11-02 ｜ 本誌更新 2026-11-02 ｜ 原典の発表・執筆 2026-10-30

発行：Now on AIr 編集部（記事制作にAIを使用）｜編集責任者：山中秀斗

ニュースの要点

  • 「Industry Evaluation Data Generation Platform」は、架空の会社の環境、質問の自動生成、品質の評価の3つで構成
  • 職業データや求人情報、SECへの提出書類など公開データをもとに環境を作り、顧客データは使わない
  • 製薬、資本市場、IT・ソフトウェアの3業界の環境を作成。品質の複合指標は初期の手法より39％向上
  • 作ったデータは社内の共有カタログで公開。外部への公開は本誌は未確認

架空の会社のデータで、AIの品質を繰り返し測る。

架空の会社でCopilotを試す

Microsoft Researchは10月30日のブログで、「Industry Evaluation Data Generation Platform」を紹介した。O*NETの職業データ、求人情報、SECへの提出書類などの公開データをもとに、実在の組織に近い架空の会社の環境を作る。顧客のデータは使っていない。

製薬、資本市場、IT・ソフトウェアの3業界の環境を作り、それぞれに数百人のユーザーとやり取りの履歴がある。汎用の質問の型を業界らしい自然な質問に変える6段階の処理と、構造の忠実さ、文脈の妥当さ、振る舞いの自然さ、安全性の4観点の品質評価を組み合わせる。

効果と使い道

品質の複合指標は初期の手法より39％高まり、一部の環境は1.0満点で0.9を超えたという。評価用データづくりは数日かかる手作業から自動処理に変わり、1つのデータセットあたり約10万ドル、全体で約30万ドルの節約と見積もっている。

会議の要約や、やるべきことの抽出など、Copilotの実際の使い方を想定した評価に使い、社内で最初の標準的な評価の基準として位置づけている。作ったデータは社内の共有カタログで公開しており、外部への公開や論文の有無は本誌は未確認。

本誌の考察・実務提案

Lakkanの視点｜社内AIの評価は「本物のデータ」なしでも始められる

AIを社内に入れるとき、本物の顧客データでは試しにくく、評価が後回しになりがちだ。今回の取り組みは、架空のデータでも業界らしい質問を作れば、品質を繰り返し測れることを示している。

本誌は、自社でAIを導入する前に、業務によくある質問を20〜30件ほど架空の資料とともに用意し、更新のたびに同じ質問で結果を比べることを勧める。これは本誌の提案で、Microsoftの推奨ではない。

現場で試す3つのこと

  1. 自社の業務でAIに頼みたい質問を、20〜30件書き出す
  2. 顧客情報を含まない架空の資料で、評価用のセットを作る
  3. AIの設定やモデルを変えるたびに、同じ質問で結果を比べる
