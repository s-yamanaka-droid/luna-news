Anthropic、新規株式公開の価格を1株83ドルに決定　9億8,000万株を売り出し、Nasdaqに銘柄コード「ANT」で上場

Anthropicは米国時間11月18日、新規株式公開（IPO）の公開価格を1株83ドルに決めたと発表した。クラスA普通株式9億8,000万株を売り出し、11月19日からNasdaq Global Select Marketで銘柄コード「ANT」として取引を始めた。株数と価格から計算すると、売り出し総額は約813億ドルになる。

ニュースの要点

  • 公開価格は1株83ドル。売り出しはクラスA普通株式9億8,000万株
  • うち9億5,635万1,354株は会社が新たに発行し、2,364万8,646株は既存株主の売り出し。既存株主分の代金は同社に入らない
  • Nasdaq Global Select Marketで、11月19日から銘柄コード「ANT」で取引開始。払い込み（クロージング）は11月20日の予定
  • 引受会社は30日間、最大1億4,700万株を追加で買い取る権利を持つ

価格の次は、開示を読む番だ。

公開価格と株数

Anthropicは米国時間11月18日、自社サイトで新規株式公開の価格決定を発表した。公開価格は1株83ドルで、売り出すのはクラスA普通株式9億8,000万株。このうち9億5,635万1,354株は同社が新たに発行する株、2,364万8,646株は既存株主が売る株である。既存株主が売る分の代金は同社には入らないと明記している。

発表は調達総額を書いていない。株数と価格から本誌が計算すると、売り出し全体で約813億ドル、会社が新たに発行する分で約794億ドルになる。引受手数料などを差し引く前の概算である。

上場市場と今後の日程

株はNasdaq Global Select Marketに上場し、11月19日から銘柄コード「ANT」で取引が始まった。払い込み（クロージング）は、通常の条件を満たしたうえで11月20日に予定している。米証券取引委員会（SEC）は11月18日に登録届出書の効力発生を宣言した。

引受会社には30日間、最大1億4,700万株を追加で買い取る権利がある。目論見書の入手先としてGoldman SachsとMorgan Stanleyが挙げられている。上場初日の株価の動きは発表には含まれておらず、本記事では扱わない。調達資金の具体的な使い道も、この発表では未確認である。

本誌の考察・実務提案

Lakkanの視点｜開示が増えることを、利用企業の判断材料にする

これは本誌の解釈だが、上場によってAnthropicは四半期ごとの業績や事業上のリスクを開示する立場になった。Claudeを業務に使う企業にとっては、提供元の財務や方針を公開情報で確かめられるようになる、という意味が大きい。

本誌は、Claudeを使っている企業に、株価の上下ではなく、料金・提供条件・データの扱いの変更が開示や発表に出ていないかを定期的に確認することを勧める。これは本誌の提案で、Anthropicの推奨ではない。

現場で試す3つのこと

  1. 自社で使っているClaudeの契約形態（個人・チーム・API）と、料金や利用条件の見直し時期を一覧にする
  2. Anthropicの決算発表やSECへの開示を確認する担当と頻度を決める
  3. 特定のAI提供元に頼りすぎていないか、代替手段を含めて点検する
