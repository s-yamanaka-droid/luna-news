Anthropic、コードの取り込みまでを支える「Claude Ship」を発表　レビュー後の修正と承認をAIが手伝う、TeamとEnterprise向けにベータ提供

Anthropicは11月23日、GitHub上のコード変更をレビューから取り込みまで支援する「Claude Ship」を発表した。一般提供済みのCode Reviewに、修正を手伝う「PR Steward」と承認を手伝う「Claude Approvals」（いずれもベータ）を組み合わせる。

ニュースの要点

  • Claude Shipは、Code Review（一般提供済み）、PR Steward（ベータ）、Claude Approvals（ベータ）の3つで構成
  • 対象はClaude TeamとEnterpriseプランの組織で、GitHub上のリポジトリのみ
  • 料金はプラン料金とは別のトークン量課金。Code ReviewとPR Stewardには管理者が月の利用上限を設定できる
  • Zero Data Retention、HIPAA構成、顧客管理の暗号鍵（CMK）を使う組織は利用できない

書く速さの次は、確認と取り込みの設計。

3つの機能で構成

Claude Shipは、GitHubでのコード変更（プルリクエスト）を、レビューから取り込みまで支援する仕組みだ。すでに一般提供しているCode Reviewに、ベータの「PR Steward」と「Claude Approvals」を加えた。Code Reviewのレビューの深さは、Quick・Standard・Deepの3段階から選べる。

Claude Codeとデスクトップアプリでは、発表当日から `/ship` コマンドの段階的な提供を始めた。`/ship` の実行分は、通常のClaude Codeの利用量に含まれる。

提供条件と料金

対象はClaude TeamとEnterpriseプランの組織で、GitHub上のリポジトリに限られる。料金はプラン料金とは別のトークン量課金で、Code ReviewとPR Stewardには管理者が月の利用上限を設定できる。Claude Approvalsに基本料金はないが、ポリシーの判定に使う分類器は課金対象になる。

Zero Data Retention、HIPAA構成、顧客管理の暗号鍵（CMK）を使う組織は利用できない。条件を満たすEnterprise組織は、最低1万ドル分のClaude Shipクレジットを2027年1月15日まで申請でき、申請後30日以内に使う必要がある（条件あり）。

一部報道にある、PR Stewardの実行環境やGitHub側の保護ルールとの関係の細部は、今回読んだ発表文では確認できず未確認である。

本誌の考察・実務提案

Lakkanの視点｜速く書けるほど「確認の設計」が効く

これは本誌の解釈だが、AIでコードを書く速さが上がった結果、詰まりやすいのはレビュー待ちと承認になってきた。Claude Shipはその後ろの工程に手を入れる製品と言える。

試す場合は、AIに承認を任せてよい変更の種類と、月の利用上限を先に決めておくのが安全だ。これは本誌の提案である。

現場で試す3つのこと

  1. AIに承認を任せてよい変更と、人が必ず見る変更を書き出す
  2. Code ReviewとPR Stewardの月の利用上限を決めてから試す
  3. 影響の小さいリポジトリ1つで、確認待ち時間と費用を記録する
